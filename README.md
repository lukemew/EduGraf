
# 🧠 EduGraf – Sistema de Automação de Planilhas Educacionais

**EduGraf** é um sistema web desenvolvido para a Secretaria de Educação do Município, com o objetivo de automatizar o processamento de planilhas do Diagnóstico de Leitura e Escrita (DLE), gerando gráficos e relatórios visuais de forma rápida e intuitiva.

---

## 🚀 Funcionalidades

- Upload de planilhas `.xlsx` preenchidas pelas escolas
- Consolidação automática dos dados de leitura e escrita por polo
- Geração de gráficos de barras comparativos por escola e polo
- Download da planilha final com os gráficos incorporados
- Interface web simples e acessível

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** React + Vite (JavaScript)
- **Backend:** Python (FastAPI ou Flask) *(em desenvolvimento)*
- **Processamento:** Pandas, OpenPyXL, Matplotlib
- **Containerização:** Docker + Docker Compose *(opcional)*
